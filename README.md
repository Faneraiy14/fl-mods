# FL Mods

Моди для [FL Loader](https://github.com/Faneraiy14/fl-bridge), які встановлюються прямо з [FL Launcher](https://github.com/Faneraiy14/fl-launcher).

Цей репозиторій містить лише **готові релізи** модів. Код модів живе окремо.

## Як встановити

Відкрий у FL Launcher збірку з лоадером **FL Loader** → **Моди**. Там одразу видно весь список модів FL. Лаунчер сам перевіряє, чи мод підходить до версії гри, і звіряє контрольну суму файлу перед встановленням.

Можна й вручну: завантаж `.jar` з [останнього релізу](../../releases/latest) і поклади в теку `mods` збірки.

## Формат релізу (для автора модів)

Кожен реліз містить jar-и модів і файл `mods.json` (лаунчер читає `releases/latest/download/mods.json`, тож **останній реліз має містити всі актуальні моди**):

```json
{
  "version": 1,
  "mods": [
    {
      "id": "fl-zoom",
      "name": "Zoom",
      "description": "Наближення камери",
      "author": "Faneraiy14",
      "version": "1.0.0",
      "file": "fl-zoom-1.0.0.jar",
      "sha1": "40 hex-символів sha1 файлу",
      "size": 12345,
      "mc": ["1.14.4", "26.3"],
      "requires": [],
      "icon": null
    }
  ]
}
```

- `file` - лише латиниця, цифри, `_`, `.`, `-`, закінчується на `.jar`; файл лежить у тому ж релізі.
- `sha1` і `size` мають точно збігатися з файлом, інакше лаунчер не встановить мод.
- `mc` - діапазон версій Minecraft `[мін, макс]` включно, або `"*"`, якщо один jar для всіх версій.
- `icon` - `https://`-посилання на картинку або `null`.
